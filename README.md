**Test payments:** card `4242 4242 4242 4242` succeeds and `4000 0000 0000 0002` is declined; any `name@bank` UPI ID works and `fail@upi` fails.

**Coupons:** `WELCOME50`, `FLAT75`, `FREEDEL`, `BIGFEAST`.

## ✨ Features

### 🛒 For customers
- Browse Chennai restaurants, and **search and filter** dishes by veg, rating, delivery time and price
- **Food Mood:** pick how you feel (comfort, spicy, healthy, sweet…) and get matching dishes
- **Meal Match:** a short quiz on craving, diet, budget and speed that recommends the best dishes
- Customise dishes with **add-ons**, and update quantities in the cart
- **Coupons** with minimum order and maximum discount rules, plus clear error messages for invalid or expired codes
- **Five-step checkout:** address, delivery instructions, payment (card, UPI, wallet or cash on delivery), review and confirm
- **Live order tracking** with a status timeline and ETA
- Order history, saved addresses, account settings and **dark mode**

### 🏪 For restaurant admins
- **Dashboard** with today's sales, order totals and a 7-day sales chart
- Manage **restaurants and menus** (add, edit and remove dishes)
- Filter **orders** and update their status
- Manage **customers** (including blocking accounts) and **coupons**

### ♿ Quality
- Responsive from 320px phones to large desktops
- Accessible: skip link, labelled forms, keyboard navigation and alt text on images

| Layer | Technologies |

| **Frontend** | React 18, Vite, Tailwind CSS, React Router (hash routing), Lucide icons |
| **Data** | In-browser demo store with seeded restaurants, dishes, users, orders and coupons, saved in localStorage |
| **Hosting** | GitHub Pages, as a single self-contained HTML file |
